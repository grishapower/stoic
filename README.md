# SENECA — The Art of Time

*Письмо I. О времени*

Интерактивная философская прогулка в браузере. Вечер, римская вилла I века н. э. на берегу Кампании. Сенека встречает вас у фонтана, ведёт через сад, кипарисовую аллею и оливковую рощу к морской террасе и по дороге читает своё первое письмо Луцилию — целиком, на русском, в новом рабочем переводе с латинского.

Здесь нет очков, врагов, таймеров и маркеров. Можно идти рядом, остановиться, свернуть к морю или просто стоять и смотреть на закат: Сенека подождёт.

## Быстрый старт

```bash
npm install
npm run dev
```

Откройте http://localhost:5173, лучше в наушниках, и нажмите «Начать прогулку». Браузер попросит разрешение на звук и захват мыши.

Нужны Node.js 20+ (проверено на 22.17) и настольный браузер с WebGL2: Chrome, Edge, Firefox или Safari последних версий. Для запуска не нужны ключи API и интернет: все модели, текстуры и озвучка лежат в `public/assets`.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | идти |
| Мышь | смотреть |
| Shift | идти чуть быстрее |
| E | взаимодействие: сорвать или поднять мандарин, перечитать письмо у стола, присесть на скамью |
| R | рассмотреть плод в руке |
| Q | отпустить или бросить плод |
| Пробел | пауза / продолжение чтения |
| T | субтитры вкл/выкл |
| L | полный текст письма (с латинским оригиналом) |
| Esc | меню: настройки громкости (голос / окружение / музыка), субтитры, мышь, качество, журнал |

## VR (WebXR)

Прогулку можно пройти в шлеме: Meta Quest (браузер шлема), ПК-VR через Quest Link / Air Link или SteamVR в Chrome/Edge. Если браузер поддерживает WebXR, на титульном экране появляется кнопка «Начать в VR», а в меню паузы — «Продолжить в VR».

**Quest без ПК-VR (по Wi-Fi):**

1. На компьютере: `npm run dev:vr` — сервер с HTTPS (самоподписанный сертификат) в локальной сети. WebXR работает только в защищённом контексте.
2. В браузере Quest откройте `https://<IP компьютера>:5173` и подтвердите переход несмотря на предупреждение о сертификате.
3. Нажмите «Начать в VR».

Другой путь — USB и режим разработчика: `adb reverse tcp:5173 tcp:5173`, `npm run dev`, на шлеме открыть `http://localhost:5173`.

**Через GitHub Pages** (проще всего для Quest): сайт отдаётся по HTTPS, так что достаточно открыть его в браузере шлема и нажать «Начать в VR». Workflow `.github/workflows/pages.yml` собирает игру и публикует её при каждом пуше в `main`; один раз нужно включить в репозитории Settings → Pages → Source: **GitHub Actions**. Адрес: `https://<логин>.github.io/<репозиторий>/`. Ключи API в сборку не попадают (они только в `.env.local`, который не коммитится).

**Без шлема** (для разработки): `http://localhost:5173/?xr=emulate` подключает эмулятор IWER (Meta Quest 3, только в dev-режиме). Устройство доступно в консоли как `window.__xrDevice`: им можно двигать голову и контроллеры, нажимать кнопки, переключать на трекинг рук.

| В шлеме | Действие |
|---|---|
| Левый стик | идти по направлению взгляда (ходить по комнате тоже можно) |
| Правый стик | плавный поворот (в настройках можно переключить на повороты рывками по 30°) |
| Хват (боковая кнопка) · сжать руку | сорвать или поднять мандарин; разжать — отпустить, взмах — бросить |
| Курок · щипок пальцами | притянуть плод, на который указывает луч; нажимать кнопки на панелях |
| A / X | взаимодействие (присесть на скамью-экседру) |
| B / Y | пауза / продолжение чтения |

Мандарин берётся рукой, когда ладонь рядом с ним: контроллером (хват) или собственной рукой при трекинге рук (щипок или кулак). Каждая рука держит свой плод. Субтитры и подсказки висят в мире перед взглядом, вопрос в конце прогулки и финал — панели с кнопками. Чтобы записать мысль в журнал, нужна клавиатура: кнопка на панели выводит из VR и открывает редактор.

## Что происходит

1. **Прибытие.** Перистиль, фонтан, птицы, ветер, первые секунды без музыки. Когда вы подходите, Сенека оборачивается и здоровается.
2. **Прогулка.** Блоки письма I–IV звучат на ходу, каждый на своём участке маршрута. Сенека подстраивает шаг под текст, ждёт, если вы отстали, ставит чтение на паузу, если вы ушли далеко, и продолжает с начала прерванной фразы. У смотровой площадки — пауза и море, у перголы — его стол со свитками.
3. **Терраса.** Заключительный блок у скамьи над морем, затем тишина. Потом появляется ненавязчивый вопрос «На что я трачу своё время?»: можно остаться в тишине, перечитать письмо, записать мысли в личный журнал (только localStorage, никуда не отправляется) или пройти прогулку заново.
Попутно в саду, у перголы и в кадках на портике растут мандарины. Плод можно сорвать, рассмотреть в руке, бросить и поднять снова. Механика сделана с прицелом на будущую VR-версию, см. [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#взаимодействие-и-vr-плоды-цитрусов). Историческая оговорка: мандарины пришли в Европу лишь в XIX веке. Цитрон, достоверный для I века, включается одной константой.

4. **Завершение.** Надпись «Письмо I. О времени» и выбор: завершить прогулку или остаться в мире.

## Структура

```
src/data/narration/script.json   письмо (латынь + перевод, субтитры, эмоции, жесты) и авторские реплики
src/data/generated/              манифесты, которые пишут скрипты: озвучка, модели, текстуры

scripts/                         конвейеры: voice/ (озвучка), meshy/ (3D), assets/ (текстуры, оптимизация GLB)
assets-src/meshy/                промпты, task id, бюджет Meshy (исходники raw/ — локально, вне git)
docs/                            документация
```

Подробно — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

### Ключи API

Ключи хранятся только в `.env.local`, который git игнорирует (шаблон — `.env.example`):

```
MESHY_API_KEY=...
ELEVENLABS_API_KEY=...
ELEVENLABS_VOICE_ID=...
```

Скрипты читают ключи сами. Префикс `VITE_` не используется, поэтому ключи не попадают в клиентский бандл: это проверено поиском по `dist/` и тестом. Игра во время работы не обращается ни к каким API.

Подключить Meshy MCP для Claude Code (по желанию; ключ будет храниться в локальном конфиге пользователя):

```bash
claude mcp add-json meshy '{"command":"npx","args":["-y","@meshy-ai/meshy-mcp-server"],"env":{"MESHY_API_KEY":"msy_…"}}' --scope local
```

## Состояние прототипа и ограничения

Честный список того, что пока не финально:

- **Голос — временная заглушка.** Это офлайн-синтез Piper: мужской русский голос, понижен и замедлен, но без актёрской интонации. Его лицензия ограничена некоммерческим использованием, подробности в [docs/ASSETS.md](docs/ASSETS.md). В настройках игры это прямо указано. Распознавание речи нашло три неточности: «Сенека» иногда звучит как «Тенека», «Всё, Луцилий» и «сговорчивее» смазаны. Финальную озвучку даст `npm run voice:elevenlabs`, когда будут ключ и бюджет: весь текст — 3 212 символов, около $0.26 за прогон.
- **Сенека — модель Meshy** с ригом на 24 кости и 10 клипами. Лицо держится в основном на текстуре, пальцев нет. Нет lip-sync (ТЗ его не требует). Взгляд, жесты и кивки процедурные поверх клипов.
- **Растительность процедурная и стилизованная:** кипарисы, оливы, пинии, кусты, трава. Две оливы у смотровой площадки — модели Meshy.
- **Колонны процедурные:** Meshy не выдал подходящую тосканскую колонну.
- **Производительность** измерена на одном Mac (Retina, DPR 1.6): на «Высоком» 60 FPS на всех станциях, 2–4 M треугольников и 210–360 вызовов отрисовки. «Низкое» качество — пресет для автономного Quest 3: 100–150 вызовов и 0,56–0,78 M треугольников на глаз (в эмуляторе). Подробности и таблица — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#производительность).
- **В консоли разработки** есть одно предупреждение `THREE.Clock … deprecated`. Оно идёт из `@react-three/fiber` 9.8, а не из кода проекта. Ошибок нет.
- **VR (WebXR) — первая версия.** Проверена в эмуляторе IWER (Quest 3): вход и выход, ходьба и поворот, хват контроллером и щипком руки, бросок, 3D-субтитры, панели. На реальной гарнитуре пока не проверялась. Руки при трекинге — открытая модель `generic-hand` (MIT), пальцы двигаются по суставам. Для автономного Quest автоматически включается «Низкое» качество, укладывающееся в бюджет Quest 3 (см. «Производительность»); на самом шлеме частота кадров ещё не замерена.

Историческая оговорка: вилла — художественная реконструкция эпохи. Мы не утверждаем, что письмо было написано именно здесь, и не воспроизводим реальную внешность Сенеки.
